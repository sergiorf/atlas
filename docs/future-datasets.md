# Future datasets

Atlas grows deliberately: Receita is the identity spine; IBGE/geography follows for names and density; CEIS/CNEP/CEPIM add explainable public-risk flags; PNCP adds supplier intelligence; graph aggregates follow trusted silver/gold data. RAIS/CAGED, ComexStat, CVM, Banco Central, and DataJud remain later, separately reviewed work. Only Receita establishments is implemented in v0.1.
